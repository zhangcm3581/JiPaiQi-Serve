# 后台单页设计预览

打开 `index.html` 即可，无需安装依赖，样式和脚本均内嵌，没有外部资源。

也可启动本地预览：

```sh
python3 -m http.server 8769 --bind 127.0.0.1 --directory /Volumes/Bot/code/JiPaiQi-Serve/preview
```

访问 http://127.0.0.1:8769 。

包含：总览、租户切换、7个客户端手牌、模拟补齐并显示13张结果、租户创建与备注编辑、搜索、历史筛选和详情。新租户ID按字符串保存，初始版本为1。

这是静态设计预览，所有指标、时间、手牌和历史记录都是示例。表单修改只在当前页面内存中生效，刷新还原；没有数据库、认证或真实WebSocket连接。正式实现时再分菜单页面并连接服务端。

验证：在Codex浏览器检查了桌面布局、手牌边界、租户创建（包含前导零ID）、模拟第7份上报及结果显示；浏览器未记录JavaScript错误。390px窄屏DOM宽度未溢出。演示牌由两副完整牌确定性洗牌后划分，7份各13张，剩余13张。

## 第二版排版

租户选择改为自定义圆角菜单，展示备注与选中标记，支持方向键、Escape和键盘选择。侧栏缩为152px；7份手牌改为紧凑横行。结果使用客户端同款8行花色、13列A至K网格，不显示顶部点数表头，两副重复牌分别落在同花色的两行。

浏览器验证：1071×669窗口、页面滚动位置0时，第7行底部610px、结果面板底部579px，均在首屏；手牌横向无溢出。已验证租户切换、结果112个网格单元（包含8个花色标记）、13个有效点数以及无JavaScript错误。
