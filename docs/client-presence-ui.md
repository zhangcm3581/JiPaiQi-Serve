# 工作台客户端连接状态

总览和实时工作台按现有 `devices[].online` 显示连接状态，上报状态与时间独立保留。在线标记在手牌已上报后仍显示。管理页面的 WebSocket 状态使用“管理页面已连接”，避免和客户端连接混淆；管理端断开时客户端标为“待同步”，历史页面不显示实时连接状态。

## 当前视觉规则（2026-09-10）

保持白色背景和细分隔线，移除整行绿底、左右色条、实心状态标签和大号数量块。

- 客户端名称直接使用实际客户端 ID，避免重复显示序号和 ID；长 ID 截断并保留完整 title。
- 名称旁用小绿点和绿色“在线”，离线用低饱和红点和“离线”；窄屏可换到名称下一行。
- 待登记设备只显示“尚未连接”辅助文字，不为每个空位额外添加标签。
- 顶部用一行轻量文字汇总“在线 X / 7 ｜ 离线 X ｜ 待登记 X”。
- 行高保持紧凑，无闪烁动画；连接状态不会挤占上报状态的位置。

不修改后端或客户端协议。客户端建立 `/ws/client` 连接就登记并推送在线状态，无需先加入牌局或提交手牌。

## 验证与部署

JavaScript语法检查、git diff --check和Node渲染检查通过；检查在线、离线、已上报仍在线、管理端断线、历史页面和客户端ID转义。浏览器已验证窄屏预览。

本地预览使用示例数据，不写业务数据库。提交推送后，服务器按 [部署文档](deploy-ubuntu24.md) 执行 `sudo bash /opt/jpq/scripts/update.sh`，更新成功后刷新浏览器。GitHub 推送完成不代表服务器已部署。
