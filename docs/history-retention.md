# 最近30天手牌历史

每个租户保留结束时间（closed_at）在最近30×24小时内的全部已关闭版本，不再限制5局。恰好30天的记录保留，超过30天的记录清理。进行中的版本不按年龄删除。

启动时清理既有过期历史；每次关闭轮次时清理该租户；服务端定时过期检查每小时清理一次过期历史，闲置租户也适用。因此运行中的闲置历史最多存在约一小时清理延迟。清理关联 rounds、hands、starts、requests，保留租户、客户端登记和当前版本。清理失败事务回滚。

沿用 rounds_history/rounds_history_tenant 的关闭时间索引和 starts_round/requests_round 索引，按确切过期版本删除关联记录，不按版本号范围删除。当前状态、收牌、计算和推送不增加历史清理操作；轮次关闭事务仍可能受批量删除数量影响。没有执行 VACUUM，SQLite空闲页可复用。

当日计算统计使用独立聚合，历史删除不扣减统计。旧版本已删除的历史不会恢复，数据库备份不属于此清理范围。

仅修改本地协议分支，未部署线上。客户端无需因保留策略更新。

验证覆盖：30天边界、超过5局仍保留、活跃局不删除、关联清理、版本跳号、请求重试、旧库启动、定时清理、统计、删除失败回滚、停用与超时。
